# 大野町例規検索

岐阜県揖斐郡大野町の条例・規則を、名称・編・種別・制定日で検索できるウェブアプリです。
スマホでは「ホーム画面に追加」するとアプリとして使え、一度開けばオフラインでも検索できます。

- 公開URL: https://is1g60th-beep.github.io/ono-reiki/
- 収録データ: 大野町例規集の例規一覧と条文（毎週月曜に自動更新）
- 例規名と条文の両方で検索でき、最近の追加・改正を一覧で確認できます
- 本文: 各例規名から大野町公式サイトの本文ページへリンクしています

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリ本体 |
| `data/reiki.json` | 例規一覧（名称・制定日・種別番号・編/章・本文の指紋） |
| `data/fulltext.json` | 条文のテキスト |
| `data/changes.json` | 自動確認で見つかった追加・改正・廃止の記録 |
| `scripts/update.py` | 町の例規集を巡回してデータを作るスクリプト |
| `.github/workflows/update.yml` | 毎週月曜 3:17 に上のスクリプトを実行する設定 |
| `sw.js` / `manifest.webmanifest` | オフライン対応とホーム画面追加用の設定 |

## 自動更新

GitHub Actions が毎週月曜の未明に町の例規集を確認し、変更があれば `data/` を更新してコミットします。
すぐに更新したいときは、Actions タブの「例規データを更新」から「Run workflow」を押してください。

改正の判定は、条文テキストが前回と変わったかどうかで行っています。表記の整理など、内容に関わらない修正も「改正」として記録されることがあります。
