# 大野町例規検索

岐阜県揖斐郡大野町の条例・規則を、名称・編・種別・制定日で検索できるウェブアプリです。
スマホでは「ホーム画面に追加」するとアプリとして使え、一度開けばオフラインでも検索できます。

- 公開URL: https://is1g60th-beep.github.io/ono-reiki/
- 収録データ: 大野町例規集（内容現在 令和8年6月30日）の例規名称 378件
- 本文: 各例規名から大野町公式サイトの本文ページへリンクしています

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリ本体（検索データを内蔵） |
| `data-reiki.tsv` | 収録した例規一覧（編/章ごと。名称・制定日・種別番号・本文ID） |
| `sw.js` | オフライン用のサービスワーカー |
| `manifest.webmanifest` | ホーム画面追加用の設定 |

## データを更新するとき

`index.html` 内の `RAW` を差し替え、`sw.js` の `CACHE` 名（`ono-reiki-v1`）を `v2` などに変えてください。

出典: [大野町例規集（Reiki-Base インターネット版）](https://www.town-ono.jp/reiki_int/reiki_taikei/r_taikei_01_01.html)
